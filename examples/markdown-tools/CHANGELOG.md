# Changelog

## 1.2.0

- 预览直接位于原文右侧，左侧继续编辑、粘贴、保存和撤销，不新增标签。
- 未保存的内容在短暂输入停顿后自动渲染，后台处理并丢弃过期结果；未闭合代码/元数据仍可预览。
- Format 单独应用当前文档格式化；输入后重新获取修改建议，防止旧结果覆盖新输入。
- 切换文件时隐藏预览，返回原文件恢复；保留已有编辑器分屏。

## 1.1.0

- 新增 Markdown 格式化及左右分屏阅读/源码预览，确认后应用并一次撤销。
- 统一标题、空行、列表、表格等格式，保留代码、HTML、元数据和硬换行。
- 使用可选 `preview.markdown` 宿主能力；旧宿主返回升级说明，保留原有三个命令。

## 1.0.0

- 增加可重复更新的 Markdown 标题目录，保留正文及 Unicode 标题。
- 增加待办完成率、剩余任务及行号报告。
- 增加光标、反向及多个选区内任务状态切换，使用 UTF-8 字节修改。
- 使用 SunBook API v1、Python 标准库和默认禁网沙箱；提供命令、宿主集成与真实 PTY 安装测试。
