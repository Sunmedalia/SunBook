SunBook v0.2.0 新增本地插件、Markdown 实时预览与分支管理，并优化 Git 提交、日志和编辑性能。

### 主要更新

- **Markdown Tools 1.2.0**：在原文件右侧实时渲染未保存的 Markdown，左侧继续编辑，不增加标签；显式格式化可一次撤销，表格长内容自动换行。还支持目录更新、待办进度和任务状态切换。
- **本地插件**：API v1、Python SDK、安装与权限审核、独立进程、健康检查、超时、重启与熔断。macOS 默认限制文件访问并禁网，代码变更需重新审核；Linux 当前提供独立进程隔离。
- **Git 提交与日志**：多行提交框、自动换行和暂存数量；Changes、Untracked 等分组可用鼠标/键盘折叠；提交成功后自动显示最新记录，浏览旧历史时保留位置。
- **分支管理**：创建、切换、重命名、安全删除、合并/中止和设置上游，保护未保存缓冲区并检查并发 HEAD 变化。
- **终端与外观**：多个独立 Shell 会话，隐藏后保留会话；终端默认色与 Auto 主题，文件图标可配置。
- **性能与编辑**：异步 LSP 请求、合并重绘、诊断缓存、增量行索引、磁盘检查与文本存储回收；保留 Unicode 字素边界和撤销行为。

### 下载与运行

| 平台 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `sunbook_0.2.0_darwin_arm64.tar.gz` |
| macOS Intel | `sunbook_0.2.0_darwin_amd64.tar.gz` |
| Linux x86-64 | `sunbook_0.2.0_linux_amd64.tar.gz` |
| Linux ARM64 | `sunbook_0.2.0_linux_arm64.tar.gz` |

无需安装 Go。使用同页的 `SHA256SUMS` 校验，解压后运行 `./sunbook .`。压缩包包含程序、README、配置示例、操作手册、`examples/` 示例插件与 `sdk/python/`。

安装 Markdown Tools：在 SunBook 按 F1，运行 **Plugins: Install Local Plugin…**，输入解压目录中 `examples/markdown-tools` 的绝对路径，审核权限并启用。F1 搜索 **Markdown Tools: Format Markdown in Split Preview**，在原文件右侧打开实时预览。示例插件需要 Python 3.9+，不会自动启用。

Git 功能需要 `git`，工作区搜索需要 `rg`；语言服务器仍为可选依赖。运行 `./sunbook --doctor` 检查环境。macOS 插件要求系统沙箱可用；Linux 的文件/网络权限与当前用户一致。终端中的 fetch/pull/push 不受影响。

### 升级与验证

替换旧程序即可使用，配置继续保留。已有插件如因包内容或批准格式变化要求重新审核，请在 Plugins 中检查权限后启用。

发布流程先在 macOS 和 Linux 执行格式、依赖、竞态、vet、Python SDK 与真实终端测试，再构建四个平台安装包并生成 SHA-256 校验文件。
