SunBook v0.3.0 新增 GitHub 插件商店与内置工作区搜索，改进实时文件查找，并减少大工作区、LSP 和 Git 的处理开销。

### 相较 v0.2.0 的更新

- **插件商店**：从 Plugins → Store… 或 F1 → Plugins: Browse Store… 搜索、查看详情并在线安装 Markdown Tools 与 Text Tools；支持记住 gh-proxy 下载选择。下载校验 SHA-256、包路径和资源限制，安装后保持禁用，审核权限后启用；仍支持本地安装。
- **文件内查找**：编辑区右上方的紧凑实时查找框显示当前匹配与总数，Enter / Shift+Enter、F3 / Shift+F3 循环跳转并记住查询；修复光标位于匹配内部时的回绕，保护组合字符选区。
- **工作区搜索**：优先使用 ripgrep，未安装时自动使用内置 Go 引擎，支持智能大小写、整词、正则、路径过滤、项目忽略规则、流式结果与取消，最多显示 2000 条。搜索结果滚动条支持点击、拖动及折叠后的范围修正。
- **大工作区与绘制**：缓存相对路径并复用前次过滤结果，Quick Open 仅保留前 200 名；编辑时保留和平移旧高亮，后台更新后替换，减少闪烁；多光标绘制仅处理可见行，减少逐帧分配。基准与适用条件见[性能验证](https://github.com/Sunmedalia/SunBook/blob/v0.3.0/docs/performance.md)。
- **LSP 增量同步**：服务器支持时，仅发送编辑、撤销和重做的改动范围；版本未变不重复发送，无法确认状态时回退全文。
- **Git 刷新**：状态刷新通常由每轮 6 个 Git 进程减至 2 个；Log 一次读取 40 条提交及文件列表，避免逐条执行 `git show`。
- **单文件安装包**：四个平台的压缩包都仅包含根目录下的一个 `sunbook` 可执行文件，不再附带文档、配置、示例插件和 SDK。

### 下载与安装

| 平台 | 安装包 |
| --- | --- |
| macOS Apple Silicon | `sunbook_0.3.0_darwin_arm64.tar.gz` |
| macOS Intel | `sunbook_0.3.0_darwin_amd64.tar.gz` |
| Linux x86-64 | `sunbook_0.3.0_linux_amd64.tar.gz` |
| Linux ARM64 | `sunbook_0.3.0_linux_arm64.tar.gz` |

无需安装 Go。使用本页的 `SHA256SUMS` 校验，解压后直接运行 `./sunbook .`，或将 `sunbook` 复制到 PATH 中的目录。文档、配置示例和 SDK 可在[主仓库](https://github.com/Sunmedalia/SunBook/tree/v0.3.0)查阅。

在插件商店安装 Markdown Tools / Text Tools 后，审核权限并启用；二者需要 Python 3.9+。网络不可用时可从仓库的 `examples/` 本地安装。macOS 插件使用系统沙箱；Linux 当前提供进程故障隔离，文件与网络访问权限仍与当前用户一致。

Git 功能需要 `git`；ripgrep 和语言服务器为可选依赖。运行 `./sunbook --doctor` 检查环境。内置搜索使用 Go RE2 正则及工作区内的忽略规则，不读取工作区外的全局忽略配置。

### 升级与发布验证

替换旧程序即可，保留现有配置与已安装插件。旧版安装包中的项目资料可自行保留或移除；新版无需这些文件即可启动。

CI 在 macOS 和 Linux 上执行格式、依赖校验、全量竞态测试、go vet、Python SDK 与真实 PTY 冒烟测试，并在临时目录解压验证单文件安装包的版本及 `--doctor`。发布前校验四个平台压缩包的内容与文件名，并生成 SHA-256 校验文件。
