SunBook 的首个公开版本：在终端中使用文件活动栏、多标签、分屏、Git 和内置 Shell。

### 主要功能

- **文件与编辑**：Explorer 过滤、模糊打开、语言图标、单击预览与双击固定；多光标、Unicode 字素编辑、撤销/重做及原子保存。
- **布局**：拖动标签排序或分屏；Explorer / Search / Git 侧边栏；终端底部 / 右侧切换。
- **搜索**：工作区全文搜索，支持正则、大小写、整词与路径过滤。
- **Git**：暂存、取消暂存、提交、可拖动高度的 Git Log，带语法高亮的左右版本对比。
- **语言服务**：可选 Go / Python / JS / TS LSP，提供补全、定义、引用、重命名和格式化。
- **主题**：SunBook、Tokyo Night、Dracula、Nord、Gruvbox Dark、GitHub Light，可即时切换并记住选择。

### 下载与运行

选择对应平台的压缩包，无需安装 Go：

| 平台 | 文件 |
| --- | --- |
| macOS Apple Silicon | `sunbook_0.1.0_darwin_arm64.tar.gz` |
| macOS Intel | `sunbook_0.1.0_darwin_amd64.tar.gz` |
| Linux x86-64 | `sunbook_0.1.0_linux_amd64.tar.gz` |
| Linux ARM64 | `sunbook_0.1.0_linux_arm64.tar.gz` |

压缩包包含程序、README、配置示例和操作手册。使用 `SHA256SUMS` 校验，解压后运行 `./sunbook .`。

建议使用支持真彩色和鼠标事件的 UTF-8 终端。图标默认使用 Nerd Font；普通字体请配置 `"activityIcons": "unicode"`。按 F1 打开命令面板，F4 打开终端，右上角 Help 查看快捷键。

### 可选依赖与范围

Git 功能需要 `git`，工作区搜索需要 `rg`；语言服务器需自行安装。运行 `sunbook --doctor` 检查环境。当前支持 macOS/Linux，不支持 Windows；应用内尚无 push、分支管理、DAP 调试或扩展插件。

本版本发布流程要求 macOS/Linux 的竞态测试、vet 和真实 PTY 冒烟测试通过，再构建四个平台并发布。
